# Tucán Gamer

Sitio web de catálogo para Tucán Gamer, preparado para publicarse en GitHub Pages.

## Archivos
- `index.html`: estructura de la página.
- `styles.css`: diseño y estilos.
- `script.js`: funciones e interacciones.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube estos tres archivos a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio y abre la dirección que te muestre.

## Importante
El inicio de sesión de esta versión es local al navegador; los botones de Facebook y Google son demostrativos y no autentican realmente con esos servicios. El pago en línea está marcado en el código como simulado. Los productos y datos guardados en `localStorage` pertenecen al navegador/dispositivo donde se usan; no se sincronizan automáticamente entre visitantes.

El sitio utiliza una fuente de Google Fonts y una imagen externa de Unsplash, por lo que esas partes necesitan conexión a internet.
